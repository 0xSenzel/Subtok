Test site privacy notice

This experimental sign-in page sends you to TikTok to authorize the basic profile scope. You enter your TikTok credentials on TikTok, not on this page.

The web page checks the authorization response and removes it from the browser address bar. It does not exchange the authorization code for an access token, retrieve profile information, or store a TikTok session. TikTok receives your authorization request and may record your consent.

The response passes through the hosting provider before the page loads. The provider may process request data, including URLs, under its own privacy policy. Do not use the web test if that is unacceptable to you.
